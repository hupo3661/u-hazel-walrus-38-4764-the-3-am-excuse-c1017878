One excuse line for make.fun's "The 3 AM Excuse" bounty: a hardware wallet refusing to sign a transaction at 3 AM. Last time it woke up at 3 AM, its human approved a token called DefinitelyNotAScam, so now it is a vault, not a babysitter — and its buttons sleep till sunrise. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
